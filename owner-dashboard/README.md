# Horus · Owner Dashboard

موقع متابعة لصاحب المكان — يفتحه من الموبايل أو اللابتوب من **أي مكان**
ويتابع مبيعاته، فواتيره، مرتبات موظفينه، وطلبات متجره الإلكتروني لحظة
بلحظة.

## كيف يعمل

السيرفر الموجود في تطبيق الكاشير (`Horus Desktop`) بيعرض REST API على
المنفذ `27817`. الموقع ده بيتصل بيه عبر مفتاح API، فالعميل يقدر يتابع
من أي مكان في العالم طول ما السيرفر شغّال (محليًا في المحل، أو على VPS
لو حابب).

## التشغيل

```bash
cd owner-dashboard
npm install
npm run dev
# افتح http://localhost:5177
# - رابط السيرفر: http://<server-ip-or-domain>:27817
# - مفتاح API: من شاشة "مفاتيح API" في الكاشير
```

## البناء والنشر

```bash
npm run build
# انشر مجلد dist/ على أي host (Vercel/Netlify/Cloudflare Pages)
```

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | لوحة عامة — KPIs، مبيعات 30 يوم بـ chart، آخر فواتير، تنبيهات مخزون |
| `/invoices` | كل الفواتير مع فلتر مدفوعة/غير مدفوعة وإجمالي المستحق |
| `/store-orders` | طلبات المتجر الإلكتروني مع حالة الطلب والدفع |
| `/analytics` | charts للمبيعات، أعلى 10 منتجات، أعمار الديون كـ Pie |
| `/products` | كل المنتجات مع المتاح والحد الأدنى |
| `/employees` | الموظفون مع الأساسي + البدلات - الاستقطاعات = الصافي + حالة صرف مرتب الشهر |
| `/notifications` | إشعارات النظام (مخزون منخفض، تنبيهات صلاحية، ...) |

## ميزات

- يتحدث تلقائيًا كل 30 ثانية في الـ Dashboard
- مفاتيح الـ API محفوظة محليًا في localStorage على الجهاز
- موبايل-فيرست — يشتغل على الموبايل بدون تعديل
- بيستخدم نفس مفاتيح API بصلاحية `read` (آمن)
- لو فيه أكتر من فرع، اعمل API key لكل فرع

## للوصول من خارج المحل (الإنترنت)

- اسهل طريقة: **Tailscale** أو **ngrok** يعمل tunnel لـ port 27817
- الأكثر استقرارًا: VPS صغير + reverse proxy على HTTPS
- لو الإنترنت ضعيف: استضف الـ owner-dashboard على نفس الجهاز كـ PWA
